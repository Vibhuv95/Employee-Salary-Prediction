# Employee Salary Prediction using Machine Learning

A responsive Flask web application that predicts an employee's annual salary using a trained Machine Learning model.

## Project Overview

This project predicts an employee's annual salary based on professional and demographic features.

The application includes:

- Responsive UI
- Live salary prediction
- Flask backend
- Machine Learning model
- Professional portfolio-ready interface

## Installation

Clone the repository

```bash
git clone https://github.com/your-username/Employee-Salary-Prediction.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
