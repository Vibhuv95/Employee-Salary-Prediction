Machine Learning Workflow

End-to-End workflow followed while building this Machine Learning application.

📂

Dataset

Collected and explored the employee salary dataset containing over 250,000 records.

🧹

Data Cleaning

Removed inconsistencies, verified data quality, and prepared the dataset for analysis.

📊

Exploratory Data Analysis

Visualized distributions and relationships to understand the data before model training.

⚙️

Feature Engineering

Built preprocessing pipelines using SimpleImputer, StandardScaler and OneHotEncoder.

🤖

Model Training

Trained Linear Regression, Decision Tree and Random Forest models using Scikit-Learn.

📈

Model Evaluation

Compared models using MAE, MSE, RMSE and R² Score to select the final model.

🚀

Deployment

Saved the trained model using Joblib and deployed it with Flask for real-time salary prediction.
